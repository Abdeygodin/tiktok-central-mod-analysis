# Списки блокировки

Блокируют серверы, с которых мод получает плашки «обновлений», рекламные баннеры и «новости». Сам TikTok и функции мода продолжают работать: без ответа сервера эти модули ведут себя так же, как без интернета.

| Файл | Формат | Где использовать |
|---|---|---|
| `domains.txt` | один домен на строку | NextDNS (Denylist), Pi-hole, RethinkDNS |
| `adguard.txt` | `||domain^` | AdGuard, AdGuard Home, uBlock Origin |
| `hosts.txt` | `0.0.0.0 domain` | файл hosts (root), Blokada, Pi-hole |

`instagold.download` (каталог тем оформления) в списки не включён — добавьте его вручную, если темами не пользуетесь.

`rezvorck.github.io` — это поддомен GitHub Pages: блокируется только он, остальной `github.io` не затрагивается.
